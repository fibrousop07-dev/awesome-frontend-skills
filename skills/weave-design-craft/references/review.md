# Artifact-first review
Review actual desktop/mobile screenshots and working controls. Separate objective failures from design judgment. Clarity, hierarchy, typography, imagery and brand fit each need observations tied to visible evidence; invented scores and a single average cannot erase a broken booking flow or missing images. Prioritize concrete fixes and compare the revised artifact with the same evidence. Use up to three focused review/fix cycles, stopping earlier when checks pass and no material issues remain. Report unresolved problems if the budget is reached; never relabel an iteration limit as success. A prior user rejection remains in force until the rejected issues are addressed; do not invent user approval. No extra model call is needed to rewrite todo lists.
