# awesome-frontend-skills

A pack of Claude Code skills for building and polishing frontend work: design taste, GSAP motion, accessibility, performance, and getting rid of the "AI-made" look in sites.

## What's inside

**Polish and design**
- `site-glow-up` – full pass over an already built site (design, motion, copy)
- `design-theory-pass` – fixes hierarchy, spacing, contrast and layout
- `anti-ai-glowup`, `de-ai-design`, `de-ai-copy` – strip the generic AI look from visuals and text
- `hand-redraw` – redraw stiff AI artwork so it reads as hand made
- `motion-pass` – adds motion where it actually helps
- `weave-design-craft`, `fibrous-sites`, `master-fibrous-sites` – site building workflows
- `design-system`, `banner-design`

**Animation**
- `gsap-core`, `gsap-timeline`, `gsap-scrolltrigger`, `gsap-plugins`, `gsap-react`, `gsap-frameworks`, `gsap-utils`, `gsap-performance`

**Quality**
- `accessibility`, `core-web-vitals`, `web-quality-audit`

## Install

Copy whatever you want into your Claude Code skills folder.

```bash
git clone https://github.com/fibrousop07-dev/awesome-frontend-skills.git
cp -r awesome-frontend-skills/skills/* ~/.claude/skills/
```

On Windows PowerShell:

```powershell
git clone https://github.com/fibrousop07-dev/awesome-frontend-skills.git
Copy-Item awesome-frontend-skills\skills\* $HOME\.claude\skills\ -Recurse -Force
```

Restart Claude Code and the skills show up in the list.
